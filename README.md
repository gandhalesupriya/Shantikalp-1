# Shantikalp IPR Consultancy Website

A responsive React + Vite corporate website starter for Shantikalp, using a navy, white and gold visual identity.

## Requirements
- Windows 10/11
- Node.js LTS (https://nodejs.org/)
- VS Code (optional)

## Run locally
1. Extract this ZIP file.
2. Open the extracted `shantikalp-website` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite, usually http://localhost:5173.

Keep the terminal open while viewing the local website.

## Build for publishing
```bash
npm run build
```
The production website will be created in the `dist` folder.

## Before publishing — customise these details
1. In `src/main.jsx`, replace `YOUR-EMAIL@example.com` in the `mailto:` link with the official Shantikalp email address.
2. Update the contact email and phone text in the Contact section.
3. Confirm the consultants' biographies, qualifications, designations and consent before publishing.
4. Add the official business address, social links and logo if available.
5. Review all service descriptions and engagement terms for accuracy.

## Contact form note
The current enquiry form prepares an email using the visitor's default email application. It does not store enquiries on a server. For a hosted form that submits directly without opening an email app, connect a form backend such as Formspree or your own server.

## Important
This is a website starter, not legal advice. Do not publish claims, credentials, client names, success rates or professional authorisations unless verified. Avoid inviting visitors to submit confidential invention details through the initial contact form.
